# references/

LLM-oriented references (`*-llms.txt`) for external libraries and tools.
This folder lets the agent check the exact API inside the repo instead of searching the web.

- When you add a library, save its `llms.txt` (if it has one) as `<name>-llms.txt`.
- Put the version on the first line of the file.
