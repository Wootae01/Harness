# 보안

> 🇰🇷 한국어 번역본입니다. 정본(에이전트가 읽는 문서)은 [SECURITY.md](SECURITY.md)이며, 내용이 다르면 영어본이 우선합니다.

## 비밀값
- 비밀값은 `.env*`에만 둔다. **커밋하지 않는다** (`.gitignore`).
- 에이전트는 `.env*`를 읽거나 쓰거나 출력하지 않는다. 훅이 강제한다 (불변식 I-1).
- 필요한 키 목록은 `.env.example`에 **값 없이** 적는다. 에이전트는 이 파일을 읽고 수정할 수 있다.
- 코드는 env를 **시작 시점에 한 번 파싱·검증**하고, 이후에는 검증된 설정 객체만 쓴다 (불변식 I-5).

## 사람 확인이 필요한 작업
- 배포, 데이터 삭제·마이그레이션, 외부 서비스로의 전송, 권한·인증 변경.

## 의존성
- 새 의존성을 추가하면 이유를 `design-docs/`에 남긴다. 유지보수되지 않는 패키지는 피한다.
