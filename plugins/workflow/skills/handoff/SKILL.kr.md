# /workflow:handoff — 다음 세션에 메모 남기기

> 🇰🇷 한국어 번역본입니다. 정본(에이전트가 읽는 문서)은 [SKILL.md](SKILL.md)이며, 내용이 다르면 영어본이 우선합니다.

> mattpocock/skills 의 `handoff`를 바탕으로 함 (MIT, © 2026 Matt Pocock — 이 플러그인의 `LICENSE.mattpocock` 참고).
> 바꾼 점: 메모를 프로젝트 안에 브랜치별로 저장하고, workflow 의 SessionStart 훅이 불러온다.

## 1. 저장 위치
- 브랜치 확인: `git branch --show-current`.
- 파일: `.handoffs/<브랜치>.md`, 브랜치 이름의 `/`는 모두 `-`로 바꾼다
  (예: `feat/12-context-detail` → `.handoffs/feat-12-context-detail.md`). 브랜치가 없으면(detached HEAD) `.handoffs/detached.md`.
- 파일이 있으면 **덮어쓴다** — 기록이 아니라 최신 상태다.
- `.gitignore`에 `.handoffs/` 줄이 없으면 추가하고(파일이 없으면 만든다), 추가했다고 사용자에게 알린다.

## 2. 쓸 내용
새 에이전트가 이 메모만 보고 작업을 이어갈 수 있어야 한다.
- **목표**: 이 브랜치가 무엇을 위한 것인지, 브랜치에 이슈 번호가 있으면 그 번호.
- **완료**: 끝내고 확인한 것 (어떻게 확인했는지 포함).
- **진행 중 / 다음**: 바로 다음 할 일을 먼저, 나머지는 순서대로.
- **결정 사항**: 정한 것과 이유 — 다음 세션이 다시 논쟁하지 않게.
- **열린 질문 / 막힌 것**: 사용자나 다른 무언가를 기다리는 것.
- **추천 스킬**: 다음 에이전트가 Skill 도구로 불러야 할 스킬.

규칙:
- 다른 산출물(이슈, 스펙, 계획, ADR, 커밋, diff)에 이미 있는 내용은 반복하지 않는다. 경로, URL, 이슈 번호로 가리킨다.
- 비밀값과 개인정보(API 키, 비밀번호, 토큰, 이메일)는 지운다.
- 사용자가 인자를 줬다면 다음 세션이 집중할 내용으로 보고 메모를 거기에 맞춘다.
- 메모는 사용자의 언어로 쓴다.

## 3. 마무리
파일 경로와, 이 브랜치의 다음 세션이 자동으로 불러온다는 것을 사용자에게 알린다.
